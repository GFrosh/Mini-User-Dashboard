# Mini User Dashboard

Practice project for visualizing mock user data with a custom React + TypeScript UI.

## Features

- Dashboard hero and stat cards
- Searchable user roster with active selection
- User detail panel with relative-age meter
- Age bucket and trend-strip visualizations
- Slider-based age cap filtering
- Responsive layout with a scrollable roster list

## Scripts

- `npm run dev` starts the Vite dev server
- `npm run build` runs TypeScript build and bundles the app
- `npm run preview` previews the production build
- `npm run lint` runs ESLint
